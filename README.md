# 🕐 Relógio Digital Animado

Um relógio digital moderno e interativo que **muda de cor conforme o horário do dia**! Com player de música integrado, busca de horário mundial e animações suaves. Desenvolvido com HTML, CSS e JavaScript puro.

![Preview do Projeto](link-da-sua-imagem-aqui)

## ✨ Funcionalidades

### ⏰ Relógio Digital
- **Atualização em tempo real** com alta precisão (60fps)
- **Anel de progresso** animado para os segundos
- **Animações suaves** nos números quando mudam
- **Alternância 24h / AM/PM** com clique no relógio
- **Data completa** em português com primeira letra maiúscula

### 🎨 Cores Dinâmicas
O relógio **muda de cor automaticamente** conforme a hora do dia:
- 🌙 **Madrugada** (0h-4h): Tons escuros de azul
- 🌅 **Amanhecer** (5h-6h): Laranja e rosa suave
- ☀️ **Manhã** (7h-11h): Azul e dourado
- ⛅ **Meio-dia** (12h-14h): Amarelo vibrante e rosa
- 🌆 **Tarde** (15h-17h): Laranja e vermelho
- 🌇 **Pôr do sol** (17h-18h): Tons quentes de fogo
- 🌃 **Noite** (19h-23h): Azul profundo e roxo

*Cada hora tem seu próprio gradiente personalizado!*

### 🌍 Horário Mundial
- **Busca por país/cidade** (Brasil, EUA, Londres, Paris, Tóquio e mais)
- **Bandeira do país** exibida automaticamente
- **Nome da cidade** em destaque
- **Botão rápido** para voltar ao horário local
- **Notificações visuais** para cada ação

### 🎵 Player de Música
- **5 faixas instrumentais** para estudo/trabalho
- **Controles completos**: play/pause, próximo, anterior
- **Barra de volume** com feedback visual colorido
- **Nome da música** com animação ao trocar
- **Play automático** da próxima faixa

### 📱 Design Responsivo
- **Totalmente adaptável** para celular, tablet e desktop
- **Botões com tamanho adequado** para toque mobile
- **Layout que se reorganiza** em telas pequenas
- **Transições suaves** entre tamanhos de tela

## 🎮 Funcionalidades em Detalhe

### 🕐 Interação com o Relógio
- **Clique no relógio** para alternar entre formato 24h e AM/PM
- Observe o **anel colorido** que completa uma volta a cada minuto
- Veja os **números pulsarem** suavemente quando mudam
